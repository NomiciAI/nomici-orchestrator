# Code of Conduct

## Our Standard

Nomici Orchestrator is an open-source project for building a local-first agent control plane. We want the project to be direct, technical, and welcoming to contributors with different levels of experience.

Expected behavior:

- Be respectful and constructive.
- Focus criticism on ideas, code, design, and tradeoffs.
- Assume good intent, but be clear when something is unsafe, incorrect, or out of scope.
- Keep discussions relevant to the project.
- Respect privacy. Do not post another person's private information.
- Do not share secrets, tokens, private prompts, private traces, or private customer data in public issues or discussions.

Unacceptable behavior:

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Sexualized language or unwanted attention.
- Trolling, repeated disruption, or bad-faith argument.
- Publishing private information without permission.
- Encouraging unsafe use of the project, including exposing control-plane credentials or dangerous tools without clear consent.

## Enforcement

Maintainers may remove comments, close issues, block users, or take other moderation action when behavior harms the project or community.

If you need to report a conduct issue, contact the maintainers privately. If the issue is also a security vulnerability, follow `SECURITY.md`.

## Scope

This Code of Conduct applies to project spaces, including GitHub issues, pull requests, discussions, documentation, chat spaces, and project events.
